## 🛠️ Projects

### 📄 DocFlow — Distributed Document Processing Platform

**Ongoing Project**

DocFlow is an event-driven backend system designed to process document-related jobs asynchronously using a distributed microservices architecture. The project focuses on understanding real-world backend patterns such as event-driven communication, failure handling, retries, dead-letter queues, and idempotency rather than building another simple CRUD application.

When a job is submitted, the **job-service** persists it and publishes an event to Kafka. The **processing-service** consumes the event, performs the processing work, and publishes a result event. The **notification-service** consumes the result and handles user notifications. Services communicate asynchronously through Kafka topics.

* **Failure handling:** Retry with backoff and dead-letter topics for failed message processing
* **Idempotency:** Idempotency keys prevent duplicate job creation when clients retry requests
* **Architecture:** Event-driven microservices with asynchronous Kafka-based communication

**Tech Stack:** Java 21, Spring Boot 4.1, Apache Kafka, Spring Data JPA, H2, Maven, Docker, Docker Compose, JUnit 5, Mockito, Testcontainers, Swagger/OpenAPI
